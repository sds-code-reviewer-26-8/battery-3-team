## 관찰 사항

- **SIM-12** 최대 수량 100,000K 시뮬레이션은 응답이 약 0.14초(142ms)로, 제한 시간(60초)에 한참 못 미칩니다. 엑셀 '확인 필요 사항'의 성능 우려(완전 탐색이 오래 걸릴 수 있음)는 이 입력(각 나라 25,000K, 방문 3~13회)에서는 해당하지 않았습니다.
- **SIM-21** 베트남 2,000K 단독 주문: 5일째 출항 · 10일째 도착 · 15일째 복귀, 운항비 10.00억원, 총 비용 21.00억원이 세 경로 모두에서 시나리오의 손계산 값과 일치했습니다.
- **SIM-18** 일본 4,500K 단독 주문: 세 경로 모두 왕복 3번, 적재량 2,000K · 2,000K · 500K 순서로 나왔습니다.
- **SIM-13** 100,001K 입력 시 서버 오류 문구 '총 생산 필요 수는 100,000K 이하여야 합니다'가 표시되고 결과 영역은 숨겨졌습니다.

## 다시 실행하는 방법

앱을 먼저 실행한 뒤(기준 정보는 기본값이어야 함):

```
cd e2e
npx playwright test tests/sim.spec.ts
```

원본 데이터는 `e2e/results/headless-run.json` 입니다. (`last-run.json` 은 가장 최근 실행 결과로 다음 실행 때 덮어써집니다.)
