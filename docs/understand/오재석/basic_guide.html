한국이 4개 공장에 셀을 주문하면 배로 수거하는 일정을 계산하고, 경로를 골라 주문을 확정하는 Spring Boot 앱입니다.

    ② 어떤 파일이 무슨 일을 하나

    파일 카드를 클릭하면 역할과 핵심 메서드가 오른쪽에 나옵니다. 위 범례로 레이어를 필터링할 수 있어요.

    ③ Planner — 경로를 어떻게 계산할까

    슬라이더로 주문량을 바꾸면 공장 하나가 “수거 가능 시점”까지 재고를 쌓는 모습을 볼 수 있습니다. (배 이동 일수는 제외한 공장 측 단순 모형)

    선: 재고(K), 점선: 재고 상한, 세로선: 수거. 재고가 상한에 닿으면 생산이 멈추고 수거를 기다립니다.
    핵심 규칙
    • 0일차에 모든 공장이 동시에 생산 시작
    • 하루 생산 = min(하루 최대, 재고 상한−재고, 남은 주문)
    • 방문 횟수 = ceil(주문 / 재고 상한)
    • 한 나라는 한 척의 배만 방문, 도착 시 재고 전부 적재
    • 여러 번 수거 → 한국에 내려놓고 재출항
    • 배는 재고가 찰 날에 맞춰 늦게 출항 (한국 대기 무료)
    3가지 결과 옵션
    COST 운항비 최소
    나라 분할 × 왕복 패턴(FRONT/BACK/SPREAD) × 방문 순열을 완전 탐색해 운항비 최소(동률이면 짧은 일수).
    FAST 가장 빠르게
    같은 후보 중 총 일수 최소(동률이면 낮은 운항비).
    NEAR 가까운 곳부터
    한국에서 가까운 나라를 배에 돌려가며 배정, 왕복마다 가까운 곳부터 방문.
    Planner 내부 파이프라인
