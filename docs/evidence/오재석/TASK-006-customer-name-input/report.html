2구현 요약

구현한 것주문 추가 화면에 고객사 입력칸이 생겼다. 주문 상세에 고객사가 표시되고 확정·진행 상태에서는 수정·저장할 수 있다(완료 상태는 수정 UI 없음, 서버도 400 으로 거부). 주문 목록 맨 끝에 고객사 열이 생겼고 값이 없으면 - 로 보인다.
접근 방법Order 에 nullable customerName(길이 100) 추가, 서비스에서 앞뒤 공백 제거·공백만이면 null·100자 초과 400 으로 정규화. 수정은 PUT /api/orders/{id}/customer(본문 customerName, version), 상태 400 · 삭제/없는 id 404 · version 불일치 409, 이력은 남기지 않고 갱신된 상세를 응답. 화면은 모두 esc() 로 이스케이프. 기존 테스트 기준은 낮추지 않고 lst.spec.ts 헤더 기대값에 열만 추가.

  • 화면을 사람 눈으로 보는 확인(레이아웃, 8080 브라우저 화면에서의 - 표시)은 하지 않았다. 대신 Playwright 가 DOM·텍스트를 단언했고, 8080 은 GET 응답과 HTML 머리글만 확인했다. 시각 확인은 사람이 한다.
