1반복 횟수

한 줄 요약: 공장별 하루 운영비(기본 1억)를 기준 정보에 추가하고 운영비 = 주문 공장 일 운영비 합 x 총 소요 일수를 총비용에 포함했다. COST 안은 "비용 최소"(운항비+운영비 최소)로 바뀌었다. 전체 테스트 49건이 모두 통과했고 계획 대비 실제도 통과했다.

2구현 요약

구현한 것기준 정보 화면에 공장별 하루 운영비(억 원, 소수 입력, 0 허용) 입력칸이 생겼다. 계획안·확정 주문·주문 목록·상세에 운영비가 표시되고 총비용 = 생산비+운항비+운영비이다. 운영비 도입 전 주문은 "-" 로 표시된다.
접근 방법Planner 후보 탐색에서 운항비 + 일 운영비 합 x totalDays 로 비용 최소를 고르고, toPlan 에서 운영비·총비용을 계산한다(schedule·simulateFactory 는 수정 없음). 확정은 서버 재계산 plan 값을 Order 에 저장한다. Factory/Order 의 새 컬럼은 nullable 이고 null 은 기본 1억으로 간주한다.
